1. 通配符：

   ```bash
   ~- : 当前目录的上一级目录，等价于 ../
   ~+ : 当前目录，等价于 .
   ?	: 任意一个字符
   *	：所有字符，无法匹配隐藏文件
   [0-9]:表示取值范围为0-9，匹配任意方括号范围内的取值,[aA]表示匹配a或者A
   [a-z]:匹配a-z的字符
   [A-Z]:匹配A-Z
   [^a-g]:^代表不匹配，这里的意思是除了a-g字符都匹配
   ```

   ```bash
   tqx@linux-ubuntu:~/linux-learn/shell/tongpeifu$ touch file{0..9}.txt
   tqx@linux-ubuntu:~/linux-learn/shell/tongpeifu$ ls
   file0.txt  file1.txt  file2.txt  file3.txt  file4.txt  file5.txt  file6.txt  file7.txt  file8.txt  file9.txt
   
   tqx@linux-ubuntu:~/linux-learn/shell/tongpeifu$ ll file[0-2]*
   -rw-rw-r-- 1 tqx tqx 0 Sep 18 20:42 file0.txt
   -rw-rw-r-- 1 tqx tqx 0 Sep 18 20:42 file1.txt
   -rw-rw-r-- 1 tqx tqx 0 Sep 18 20:42 file2.txt
   
   tqx@linux-ubuntu:~/linux-learn/shell/tongpeifu$ ls file[0-2]*
   file0.txt  file1.txt  file2.txt
   ```

2. 通配符(man 7 glob)：

   ```bash
   #注意：以下的通配符均代表不加[]的内容，比如[:lower:]代表a-z，如果使用它匹配时，需要再添加[]，即：[[:lower:]]
   [:lower:]:表示所有小写字母，等价于a-z
   [:upper:]:所有大写字母
   [:digit:]:0-9
   [:alpha:]:任意大小写字母
   [:alnum:]:任意字母与数字
   [:blank:]:水平空白字符
   [:space:]:水平或垂直空白字符
   [:punct:]:标点符号
   [:print:]:可打印字符
   [:xdigit:]:十六进制字符
   ```
