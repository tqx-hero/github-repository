1. SSH远程链接服务器：

   ```shell
   ssh [-P 端口号] root@192.168.1.178
   ```

2. 文件上传到服务器：

   ```shell
   scp [-P 端口] a.out root@192.168.1.178:/home
   ```

   

3. 文件下载到服务器：

   ```shell
   scp [-P 端口号] [-r表示下载的是文件夹] root@192.168.1.178:/home/a.out ./	
   ```

   

4. 连接某个服务器如:192.168.1.178:9000:

   ```shell
   nc 192.168.1.178 9000
   ```

5. vim/vi编辑器显示文本行数：

   ```shell
   :set nu
   ```

   

6. 复制整行数据：

   ```shell
   //vim在无法编辑的状态下
   yy
   ```

   

7. 剪切整行数据：

   ```shell
   dd
   ```

   

8. 粘贴整行数据：

   ```shell
   p
   ```

   

9. 监视网络套接字连接情况：

   ```shell
   netstat [-options]: 
   #	常用:netstat -natp 
   #	当然可以在后面添加管道进行筛选，
   #	比如:筛选端口号为9000的：netstat -natp | grep 9000
   #选项如下：
   options:
   	-a:all
   	-t:tcp
   	-u:udp
   	-p:programs(显示正在使用套接字的程序信息)
   	-r:route(显示路由表)
   	-n:numeric(不适用域名，直接使用ip地址)
   ```

   

10. 自动匹配补全功能：

    ```shell
    ctrl+n(大小写敏感，且需要完全匹配前半部分)
    ```

    

11. 查看内核版本：

    ```shell
    uname -r (-a是全部信息)	
    ```

    

12. 查看操作系统信息：

    ```shell
    cat /etc/os-release
    ```

    

13. 查看当前目录的完整绝对路径：

    ```shell
    pwd
    ```

    

14. 查看某个文件夹下面的文件(以/bin目录为例):

    ```shell
    ls [-op] /bin
    #选项：
     -a:all
     -l:list
     -h:显示文件大小（K/M等等），以字节为单位
     #可以同时使用，比如: ls /bin -alh
    ```

    

15. 查看命令、函数、结构体等手册：

    ```shell
    man 1 ls (查看ls命令)
    #man命令：
    	第一章存放的是命令
    	第二章存放的系统调用函数
    	第三章存放的库函数
    ```

    

16. 查看某个已知道开头的命令：

    ```shell
    #以ipconfig为例，如果忘了具体命令，只知道首字母为i，那么可以使用如下命令：
    i (点两下制表符\t,即可显示出所有以i为开头的所有命令)
    ```

17. 查看ls命令的可执行文件所在位置：

    ```shell
    which ls
    ```

    

18. 查看网络连接信息(ip地址)：

    ```shell
    ifconfig
    #或者用：ip addr来查看ip信息
    ```

    

19. 查看已键入的命令历史记录：

    ```shell
    history
    ```

    

20. 清屏幕：

    ```shell
    clear
    ```

    

21. 安装命令tree：

    ```shell
    sudo apt install tree
    ```

    

22. 以树形结构展示当前目录下的所有文件：

    ```shell
    tree [./] [-L 2] #-L 2可表示 显示2层
    ```

    

23. 安装posix手册：

    ```shell
    sudo apt install manpages-posix-dev
    ```
