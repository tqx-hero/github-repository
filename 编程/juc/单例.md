### 单例：

饿汉式和懒汉式：



饿汉式-线程安全：

```java
public class Hungry {
    private static Hungry instance = new Hungry();

    private Hungry() {
    }
    public static Hungry getInstance() {
        return instance;
    }
}
```



懒汉式：

​	1、构造方法（new对象）线程不安全：

```java
public class LazyNoSync {

    private static LazyNoSync instance;

    private LazyNoSync() {
    }

    public static LazyNoSync getInstance() {
        if (instance == null) {
            instance = new LazyNoSync();
        }
        return instance;
    }
}
```

2、DCL：线程安全，高并发可能会出现半初始化问题

```java
public class LazySync {

    private LazySync() {
    }

    private static LazySync instance;

    public static LazySync getInstance() {
        if (instance == null) {
            synchronized (LazySync.class) {
                if (instance == null) {
                    instance = new LazySync();
                }
            }
        }
        return instance;
    }
}
```

3、匿名内部类：利用了类加载机制，类只加载一次的特点

```java
public class InnerClass {
    private InnerClass() {
    }

    private static class Inner {
        private static InnerClass instance = new InnerClass();
    }

    public static InnerClass getInstance() {
        return Inner.instance;
    }
}
```

4、枚举：（汇编后生成的是final类，INSTANCE生成的是public static final类型的常量）

```java
public enum SingletonEnum {
    INSTANCE;
}
```
