## KMP

针对字符串的匹配问题的暴力算法（BF）出现的回溯重复比较的优化。优化思想如下：

1. BF算法每次在模式串与正文串在下标为i位置匹配失败时，正文串会从i下标回退到开始位置+1（回溯），然后重新与模式串从头匹配。这种回溯算法充满了大量的重复比较。

2. KMP算法的思路是如果模式串与正文串在匹配途中出现不匹配的情况，说明在出现这个不匹配时，比如说模式串长度为4，在模式串匹配到第i=3下标位置，也就是最末位出现不匹配的情况时，那前三个位置下标0-2的字符是能够匹配上的。既然有能够匹配的字符，那如果在回溯的时候省去比较这些能匹配的字符，那就会节省大量的时间，使得BF的算法时间复杂度大大降低。（不止是KMP算法，关于字符串的匹配问题都是要尽可能的省去重复比较的字符，包括BM算法也是这样）

3. 所以KMP算法就阐述了一种思路：在出现i下标匹配不上时，正文串不回退，只回溯模式串，让模式串回退到一个适当的位置，使得这个字符与正文串的i-1下标相同，前面的字符也能对齐，这样再次从这个位置开始往后比较即可，至于前面已经对齐的字符，因为是之前已经匹配成功了，就没必要再次比较，这样就省去了这几个字符的比较。

4. 由此想跳过这几个字符，那就看这几个字符（一个或多个）在模式串的这个位置之前的子序列中有没有再次出现过，出现过的最晚位置是哪里，如果找到这几个字符在模式串中出现的上一个位置的下标，那在3步骤出现匹配失败时，直接让这几个字符的next位置与i位置对齐，之前的必然能够与正文串对齐，所以KMP的算法问题就是如何找到这几个字符，以及如何得到这几个字符的上次出现的开始位置index。

5. KMP的三位大佬想出了最长前后缀的求解思路。就是求每一个位置i之前（从0~i-1）的子序列中，找到最长的前后缀，让这两个子序列长度相同，字符相同，并且不能有交集(**比如：ABABA，这个子序列满足条件的最长前后缀为AB，不是ABA，因为第2位的A是两者的交集**)，找到后得到它的长度，这个长度就是这个前缀子序列结束后的第一个不是子序列的字符的下标（**还是以上ABABA，长度为2，因为是前缀，所以下标都是从0开始计算，下标为2的那个字符整好是A，也就是最长前缀结束后第一个字符**）。

6. 就这样找到模式串每个下标对应的它前面的符合条件的最长前后缀子序列的长度，并将它们记录到一个数组next[]中。这个数组就是当在模式串与正文串进行匹配，在对应下标匹配失败时，应该让模式串回退的位置，正文串保持下标不动，再次以这个位置开始继续匹配。如果出现这个next对应值为0，说明这个下标前面元素不能找到前后缀，就不能与正文串对齐。这种情况就需要让正文串指针往后挪，从i+1位置从头开始比较。

7. ###### 举个例子：ABABAC这个模式串，它对应的next[]的值为{0,0,0,1,2,1}。

   1. ###### 由于这里的前后缀不能有交集，而且要保持相同长度必须相等，所以没有前后缀的下标0，还有有且只有前后缀其中一个下标1，它俩的next值必定为0。

   2. ###### 从下标2开始，下标2位置是A，它前面子序列是AB，只有一种情况：前缀A后缀B，这俩不相同，所以next[2]=0。

   3. ###### 下标3，数据是B。前面子序列：ABA，长度为3，以中间B为界分割为前缀A后缀A，显然前后缀都是A，符合条件，长度为1，next[3]=1。

   4. ###### 下标4，数据：A，子序列：ABAB。分割前后缀子序列分别为：AB、AB，符合条件，next[4]=2。

   5. ###### 下标5，数据C，子序列：ABABA。以中间的A为界分割前后缀：AB、BA。这俩不相同，因为长度大于1，那就找比这个前后缀更短的，前缀指针从末尾往前挪，后缀指针从前往后挪，同时挪一位（这里做的就是让指针挤压子序列长度，每次长度-1，一直减到0），继续看它们是否相同，不能就继续指针挪动，直到长度归0。这里指针挪动之后前后缀都成了A，那它的长度就是1，next[5]=1；

8. ##### 关于7的示例，是一种暴力匹配，通过分割成两个子序列，从最大长度开始对比，用来求解的思路。其实还能再优化，因为我计算i位置时的next值，就是找它前面最长前后缀匹配的下标时，因为i-1的next已经算出来了，=也就是i-1位置的那个最长子序列对应位置已经有了，我只需要去对比i-1位置的这个字符，与它对应的next[i-1]下标的那个字符是否相同。如果相同，那直接在next[i-1]的基础直接+1，这就是next[i]的值，即：next[i]=next[i-1]+1。

9. ##### 但是如果不相同，表示i-1位置与它前缀对应的结束位的位置字符不同，比如这个位置是j，那就找这个位置所在下标next[j]所在的字符是否与i-1相同，如果不同，再往前倒，一直倒到下标为0为止。如果为0下标的字符还是不与i-1字符相同，那就说明没有匹配的前后缀，那就设为0。

10. ##### 从这就能看出这是一个递推公式，可以通过迭代或者递归来求：

```java
//给j赋值next[i-1]，判断i-1位置的字符与next[i-1]位置的是否相同
//不同则继续赋值，往前找，直到能找到相同的字符或者下标到0
//1、找到相同的字符，那就是这个位置的next+1
//没找到下标归0后，next[i]=0
for (j = next[i - 1]; j > 0 && a[i - 1] != a[j]; j = next[j]) ;
next[i] = a[i - 1] == a[j] ? j + 1 : 0;
```



##### 求出这个next[]来就可以直接以它为跳表，不匹配时找到对应的下标，然后与正文串对齐，再次比较。如果比较还不相同，让i+1，正文串指针前挪。完整代码示例如下：

```java
public class KMPAlgorithm {

    //暴力算法求最长前后缀相等的最大长度
    public static int[] getNext(String s) {
        if (s == null || s.isEmpty())
            return new int[]{};
        char[] sArr = s.toCharArray();
        int length = sArr.length;
        var next = new int[length];
        //直接跳过第一第二位
        //他俩没有前后缀或只有其中一个
        for (int i = 2; i < length; i++) {
            //前后缀的最大长度
            int max = i / 2;
            for (var k = max; k > 0; k--) {
                boolean equals = false;
                for (int j = 0; j < k; j++) {
                    //以中间为界，分别比较前后缀，相同开始记录
                    //不同的直接退出next[i]=0；
                    if (sArr[j] == sArr[i - k + j]) {
                        equals = true;
                        continue;
                    }
                    equals = false;
                    break;
                }
                if (equals) {
                    next[i] = k;
                    break;
                }
            }
        }
        return next;
    }

    //KMP算法的计算next[]方式
    public static int[] next(String s) {
        char[] a = s.toCharArray();
        int l = a.length;
        var next = new int[l];
        int j;
        for (int i = 2; i < l; i++) {
            //先获取到前一个元素的next值
//            //不相同需要查看下next[i-1]是否为0，往前递推直到0为止
            for (j = next[i - 1]; j > 0 && a[i - 1] != a[j]; j = next[j]) ;
            next[i] = a[i - 1] == a[j] ? j + 1 : 0;
        }
        return next;
    }

    public static int getIndex(String str, String s) {
        if (str == null || s == null || str.isEmpty() || s.isEmpty() || s.length() > str.length())
            return -1;
        char[] a = s.toCharArray(), b = str.toCharArray();
        int n = a.length, m = b.length;
        int[] next = next(s);
        int i = 0, j = 0;
        while (i < m && j < n) {
            if (b[i] == a[j]) {
                i++;
                j++;
            } else
                //字符不匹配，j回退到next[j],i不回退
                //j=0，表示没有相同前后缀，那就让正文串指针+1，继续重新比较
                if (j == 0)
                    i++;
                else
                    //存在前后缀的，重新设置模式串下标与正文串当前下标i对齐，再次比较
                    j = next[j];
        }
        return j < n ? -1 : i - n;
    }

    public static void main(String[] args) {
        String str = "TTTTCACTCAC";
        String s = "CACTCAC";
        System.out.println(getIndex(str, s));
//        System.out.println(Arrays.toString(next(s)));
    }
}
```
