## 排序：

1. #### 直接插入排序：

   1. 适用于有序列表，即插入时前段数据已经有序；

   2. 时间复杂度O(n^2)

      1. 从序列最末尾开始一一对比，大于该数据往后靠：arr[j]=arr[j-1]。
      2. 依次遍历，直到前方数据比要插入的数据小为止；
      3. 将数据插入到当前位置，该数据排序完成。

   3. 该排序针对有序序列。

      ```java
         public static int[] sort(int[] arr) {
              if (arr == null || arr.length == 0)
                  return new int[]{};
              int length = arr.length;
              //设置一个新的数组，长度+1，头结点作为哨兵节点可用来存放数据
              int[] orderArr = new int[length + 1];
              int sentinelIndex = 0;
              for (int i = 0; i < length; i++) {
                  orderArr[sentinelIndex] = arr[i];
                  for (int j = i + 1; ; j--) {
                      //从后往前遍历数组中的所有数据直到大于它
                      if (orderArr[j - 1] > orderArr[sentinelIndex]) {
                          orderArr[j] = orderArr[j - 1];
                          continue;
                      }
                      orderArr[j] = orderArr[sentinelIndex];
                      break;
                  }
              }
              return orderArr;
          }
      ```

2. #### 折半查找：

   1. 原理同直接插入排序，只是对其进行的优化；

   2. 将要插入的数据data放到哨兵节点或者临时变量temp；

   3. 设置头尾两个指针head、tail；

   4. 根据(head+tail)/2计算中间指针mid，对比arr[mid]数据是大于还是小于data；

   5. 如果大于data，说明最终位置在(head,mid-1)，让tail=mid-1，继续折半查找；小于data，则让head=mid+1，组成新的(head,tail)

   6. 以上述步骤最新的head与tail继续迭代查找中心点，比较缩小范围，直到head与tail相同，这就是data最终位置；

   7. 从数组末尾倒序到tail位置依次往后挪动，空出tail位置，插入data；

   8. ###### 该方法相较于直接插入排序，省去了一个个比较的操作，换成了二分查找的方法，一次缩小一半的查找范围，查找效率O(logn)极高。但是插入还是需要从后往前依次空出位置插入，最坏情况在数组开头，还是需要挪动n次数据，整体时间复杂度还是O(n^2)。

      ```java
      public static int[] halfSort(int[] arr) {
          if (arr == null || arr.length == 0)
              return new int[]{};
          int[] arrs = new int[arr.length + 1];
          int sentinel = 0;
          arrs[sentinel + 1] = arr[sentinel];
          for (int i = 1; i < arr.length; i++) {
              arrs[sentinel] = arr[i];
              int head = 1, tail = i;
              if (arrs[tail] < arrs[sentinel]) {
                  arrs[tail + 1] = arrs[sentinel];
                  continue;
              }
              for (; head <= tail; ) {
                  if (head == tail) {
                      if (arrs[tail] < arrs[sentinel])
                          tail++;
                      break;
                  }
                  //每次查找取中间值，缩小范围
                  //head 小，tail大，而且head与tail相距不超过1
                  int mid = (head + tail) >>> 1;
                  //mid小于，tail前移
                  if (arrs[mid] < arrs[sentinel])
                      head = mid + 1;
                  else
                      tail = mid - 1;
              }
              for (int j = i; j >= tail; j--)
                  arrs[j + 1] = arrs[j];
              arrs[tail] = arrs[sentinel];
          }
          return arrs;
      }
      ```

3. #### 冒泡排序：

   1. 原理非常简单，从第1个位置开始，两两比较，如0/1比较，0比1大就调换位置，然后1与2比较，2和3，3和4.....直到最后一个，这样每次就能确定最大的那个数据放到最后，类似冒泡一样层层排序；

   2. 第一趟确定一个最大值，第二趟确定一个最大值，每次都会确定一个最大值排到后面，直到排到最前面。

   3. 操作非常简单，实现也不复杂，时间复杂度稳定O(n^2)。

      ```java
      public static int[] maopaoSort(int[] arr) {
          if (arr == null || arr.length == 0)
              return new int[]{};
          int n = arr.length;
          //表示在排序是是否没有存在过数据位置调换
          //如果有没有数据交换，说明已经排好序了
          //此时可直接返回，不再需要遍历
          boolean ordered = false;
          //需要i趟比较
          for (int i = 1; i <= n - 1 && !ordered; i++) {
              ordered = true;
              //每趟比较n-i次
              for (int j = 0; j < n - i; j++) {
                  if (arr[j] > arr[j + 1]) {
                      arr[j] = arr[j] ^ arr[j + 1];
                      arr[j + 1] = arr[j] ^ arr[j + 1];
                      arr[j] = arr[j] ^ arr[j + 1];
                      ordered = false;
                  }
              }
          }
          return arr;
      }
      ```

4. #### 简单排序：

   1. 从i=0或1开始，与数组中其他数据进行逐一比较：01比较、02比较、03比较....，每次比较都记录最小数据的下标；

   2. 一趟下来统计到最小数据的index，将arr[0]与arr[index]数据位置调换，这样第一趟就找到了最小值；

   3. 第二趟从第二个位置开始，与后面的数据再次逐一比较，找到最小值，调换；

   4. 第三趟从第三个位置开始，与后面再次比较，找到最小值调换。。。。

   5. 以此类推，直到找到所有最小值调换完成，排序结束。

   6. 与冒泡排序类似，冒泡是两两比较找到最大值排到最后，简单排序是不调换位置，每次只找最小值然后调换这两个数据的位置。

   7. 时间复杂度上，与冒泡一样都是标准的O(n^2)，虽然没有逐一调换位置，但还是进行一一查询的。

      ```java
      public static int[] order(int[] arr) {
      
          if (arr == null || arr.length == 0)
              return new int[]{};
          int length = arr.length;
          //一共进行长度-1趟排序
          for (int i = 0; i < length - 1; i++) {
              int minIndex = i;
              for (int j = i + 1; j < length; j++) {
                  if (arr[minIndex] > arr[j])
                      minIndex = j;
              }
              //互换最小值与i的位置
              int temp = arr[minIndex];
              arr[minIndex] = arr[i];
              arr[i] = temp;
          }
          return arr;
      }
      ```

5. #### 希尔排序：

   1. 与之前直接插入排序原理相同，也是两两进行比较，小的排前面，大的排后面，是直接排序的升级版本。

   2. 加入了增量序列gap的概念。相较于直接插入排序的临近位置两两比较调换，希尔排序让间隔某一个常数的两个数据进行两两比较。

   3. 具体做法是：设置多个增量，增量由大到小，初始增量可以设置数组长度的一半。

   4. 让数据与间隔这个增量的数据进行比较，如：设置gap=5，则i0与i5比较，i1与i6....；依然是小的放前面，大的放后面

   5. 一趟下来后，所有数据基本上已经非常接近最终位置了；

   6. 再次缩小增量，如再除以2向上取整，设置gap=3，让i0与i3、i1与i4....每一趟下来后数据都会向最终位置靠拢；

   7. 再次缩小增量，gap=1，这样就相当于直接插入排序一样，相邻位置两两比较，结束后出结果。

   8. 希尔排序实现了让数据由之前的走路式的搜寻位置，变成了坐车一样从远距离一瞬间坐到车站，只要再走一点路即可到家，效率很高。

   9. 但是不稳定，数据可能在一次增量排序过程中重复比较，这跟选取的gap值有关系，但总体来说效率非常高。

      ```java
      public static int[] shellOrder(int[] arr) {
          if (arr == null || arr.length == 0)
              return new int[]{};
          int length = arr.length;
          int gap = length >>> 1;
          while (gap > 0) {
              for (int i = gap; i < length; i++) {
                  int temp = arr[i];
                  int j;
                  //从中心位置，与前面的数据(-gap)开始比较，小的放前面
                  for (j = i; j >= gap && temp < arr[j - gap]; j -= gap) {
                      arr[j] = arr[j - gap];
                  }
                  arr[j] = temp;
              }
              //每个gap执行完一次之后/2，继续选取新的增量再次排序，直到gap=1完成
              gap /= 2;
          }
          return arr;
      }
      ```

6. #### 快速排序：

   1. 分治递归思想。选取一个值，先找出这个值在数组中的位置，比它小的放在前面，大的放在后面，然后以这个值为界分成左右两部分，分别在这两部分继续选取新值重复上述操作，再次2分4份，4分8....直到分到不能再分为止，这时数组已经排好了。

      1. ###### 数组中选取第1位置(这里0号位置为哨兵位置)，数据放入哨兵位置，设置low、high两个指针分别指向数组始末位置；

      2. ###### 由于1号位置已空出，从high位置开始往前逐步查找第一个比哨兵位置小的数据，找到后将数据添加到1号位置，high指针停止。

      3. ###### low位置开始后移，找一个比哨兵位置大的数据，放到high的空位置，结束后low停止；

      4. ###### high继续前移，重复操作，找到小于哨兵位置的数据放到low位置；

      5. ###### low后移，重复步骤；

      6. ###### low、high交替进行，直到两指针重叠，当前位置即为哨兵数据的位置，将数据拷贝过来，并以此数据为界拆分[0,low-1],[low+1,length-1]两个数组，继续重复上述操作；

      7. ###### 递归重复直到拆分数组中仅有一个数据，这时数组已经排好序。

   2. 快速排序是先将整个大数组进行一个粗略的排序，然后进行拆分，拆分后再细化再拆分，在细化的路上拆分，拆到不能再拆，那这个数组就已经排好了。典型的分治思想，每次都是折半进行操作，所以效率非常高，时间复杂度是O(nlogn)。

   3. 快速排序简单写法是递归，但是考虑到数据量非常大的话，递归调用可能会使方法栈内存溢出导致OOM，所以实际开发中如果使用还是建议改成迭代，或者直接如下使用手动栈实现，安全又高效。

   4. 下方的手动栈了与方法栈同样的功能，不同的是栈内存储的不是数组内整个Object对象，而是下标index，因为Object如果非常大的话，光拷贝对象的执行时间会拖慢整个算法，所以这里进行了优化，传递的是仅占4字节的整型，轻量快速。

      ```java
      public static int[] quickSort(int[] arr) {
          if (arr == null || arr.length == 0)
              return new int[]{};
          int length = arr.length;
          int[] arrs = new int[length + 1];
          System.arraycopy(arr, 0, arrs, 1, length);
          ArrayDeque<Integer[]> stack = new ArrayDeque<>();
          //将起始位置low与末尾high的下标打包成数组压入栈内
          stack.push(new Integer[]{1, length});
          while (!stack.isEmpty()) {
              Integer[] indexArr = stack.pop();
              //得到始末位置的坐标
              int start = indexArr[0], end = indexArr[1];
              int low = start, high = end;
              //将初始位置的数据放入哨兵位置
              arrs[0] = arrs[low];
              for (; low < high; ) {
                  for (; high > low && arrs[high] >= arrs[0]; high--) ;
                  //找到比当前哨兵位置数据更小的，放入low位置
                  arrs[low] = arrs[high];
                  for (; low < high && arrs[low] <= arrs[0]; low++) ;
                  arrs[high] = arrs[low];
              }
              //哨兵位置的数据放到遍历完成的空位置
              arrs[low] = arrs[0];
              //查看区间内剩余个数，大于1的区间继续将始末位置下标压入栈内迭代
              if (end > low + 1)
                  stack.push(new Integer[]{low + 1, end});
              if (start < low - 1)
                  stack.push(new Integer[]{start, low - 1});
          }
          System.arraycopy(arrs, 1, arr, 0, length);
          return arr;
      }
      ```

7. #### 堆排序：

   1. 利用了堆取极值是O(1)的特点，只需要维护堆的结构稳定即可不断地从堆取堆顶构建出数组即可，时间复杂度O(nlogn)。

   2. 实际开发中堆的利用还是非常频繁的，java内置了如优先队列PriorityQueue的数据结构，实现了大小顶堆的功能，直接使用即可，下方只是一个实现了小顶堆的基本功能的demo。

      ```java
      public class MinHeap {
          private static final int DEFAULT_CAPACITY = 1 << 6;
          private Integer[] val;
          private int count;
      
          public MinHeap() {
              this.val = new Integer[DEFAULT_CAPACITY];
              count = 0;
          }
      
          public void add(Integer v) {
              //添加到数组，开始上浮
              int cur, p;
              for (cur = count; cur > 0 && v.compareTo(val[p = ((cur - 1) >>> 1)]) < 0; cur = p)
                  val[cur] = val[p];
              val[cur] = v;
              count++;
          }
      
          public int peek() {
              return val[0];
          }
      
          public int poll() {
              //把最后一个元素添加到堆顶位置，然后下沉
              int res = val[0];
              int temp = val[count - 1];
              count--;
              int cur, c1;
              for (cur = 0; (c1 = cur * 2 + 1) <= count - 1; cur = c1) {
                  //这里判断另一个儿子是否存在以及数据是否小于c1
                  //小于的话c1+1即可
                  if (c1 != count - 1 && val[c1 + 1] < val[c1])
                      c1++;
                  if (temp <= val[c1])
                      break;
                  val[cur] = val[c1];
              }
              val[cur] = temp;
              return res;
          }
      
          public Integer[] getHeap() {
              return Arrays.copyOfRange(val, 0, count);
          }
      //测试用例
          public static void main(String[] args) {
              MinHeap minHeap = new MinHeap();
              int[] arr = {22, 10, 30, 20, 80, 7, 50, 33};
              for (int i : arr) {
                  minHeap.add(i);
              }
              System.out.println(minHeap.poll());
              System.out.println(minHeap.poll());
              System.out.println(Arrays.toString(minHeap.getHeap()));
          }
      }
      ```

8. #### 归并排序：

   1. 同样是分治思想，将一整个大的数组拆分成一个个length为1的数组，其中只有一个元素，然后在将这些小数组一个一个整合，整合的过程就是排序的过程，8个和4个、4个和2个、2个和成1个，最后这一个数组即为所要的结果。时间复杂度同样为O(nlogn)，效率极高，且稳定。

   2. 与快速排序理念相同，但处理过程不同，快速排序是先排序，再拆分，结束标志是拆分到一个个的单元；

   3. 归并排序是先将数据拆分成一个个的单元，然后再将其两两合并，合并过程是排序过程，结束标志是整合成只有一个数组。

   4. 该方法同样可以用递归算法来实现，因为是同样的思想。这里使用队列这种更为巧妙地处理方式，不对数组内的Object对象进行直接拆分合并，使用的是对下标的操作，整个过程只对4字节的整型进行入队出队排序等操作，效率非常高，也没有栈溢出的风险。

      ```java
      /**
       * 对两个数组进行值比较，以升序排列生成只包含index的新数组
       *
       * @param arr 原数组数据，拿来比较数据的
       * @param a1  存放数据所在的数组下标组成的子数组
       * @param a2  另一个子数组下标
       * @return
       */
      private static Integer[] twoArraysUnion(int[] arr, Integer[] a1, Integer[] a2) {
          int ia1 = 0, ia2 = 0, la1 = a1.length, la2 = a2.length, ian = 0;
          Integer[] ianArr = new Integer[la1 + la2];
          while (ia1 < la1 && ia2 < la2) {
              //在原数组中根据index拿取值进行比较，然后将满足条件的值的下标依次放入新数组内
              if (arr[a1[ia1]] < arr[a2[ia2]])
                  ianArr[ian++] = a1[ia1++];
              else
                  ianArr[ian++] = a2[ia2++];
          }
          if (ia1 == la1 && ia2 == la2)
              return ianArr;
          if (ia1 == la1)
              System.arraycopy(a2, ia2, ianArr, ian, la2 - ia2);
          else
              System.arraycopy(a1, ia1, ianArr, ian, la1 - ia1);
          return ianArr;
      }
      
      public static int[] sort(int[] arr) {
          if (arr == null || arr.length <= 1)
              return arr;
          int length = arr.length;
          //将要排序的数组下标分成若干下标组成的数组存放到队列中，然后对这些数据进行排序继续放入队列中，
          //循环直到队列中仅剩一个数组
          ArrayDeque<Integer[]> queue = new ArrayDeque<>();
          for (int i = 0; i < length; i++)
              //这里放到队列中的是对象所在数组的index，所占用空间极低
              queue.add(new Integer[]{i});
          int[] iArr = new int[length];
          //每次取两个数组，合并成一个数组，直到队列中只剩下一个数组
          while (queue.size() > 1)
              queue.add(twoArraysUnion(arr, queue.poll(), queue.poll()));
          Integer[] resultIndex = queue.poll();
          for (int i = 0; i < length; i++)
              iArr[i] = arr[resultIndex[i]];
          return iArr;
      }
      ```

9. #### 基数排序：

   1. 数据由0-9这十个数构成，创建十个位置（俗称桶）0/1/2/3/4/5..../9，专门用来存放数据，每次从个位开始比较对应index存放到桶内，如7存放到7号桶，100存放到0号，33存放到3号...；

   2. 一趟存放完成后，从0号到9号桶位依次遍历取出，这就是个位数从小到大的顺序；

   3. 继续按照十位数的值存放到不同的桶位，22到2号，45到4号....，放置后取出；

   4. 百位、千位...直到数组内最大数据所在的位数，排完后依次从0号取出，这就是数组的升序结果。

   5. 这种排序是针对数据组成设计的，专门针对数据位数的，时间复杂度为O(n*m)，其中n为数组长度，m为最大的位数。所以如果数据的位数不是很大(一般也不是非常多，除非字符串)的整型，非常适合用。

   6. 由于基数排序普通的是按照数据最大位数来进行数据入桶倒桶的，对于那些位数不够的数据，当要排序的位数超过了自身位数时就没必要再次入桶倒桶，这些数据可以直接放到新数组中，后续只对位数达标的数据再次排序即可，省去非常多的无意义的操作。

      ```java
      public class BucketSort {
      
          //定义桶位
          static class Entry {
              List<Integer> nums;
      		//提供清除List的方法，倒桶后重置桶内数据
              void clear() {
                  nums.clear();
              }
      
              public Entry() {
                  this.nums = new ArrayList<>();
              }
          }
      
          private static Entry[] initBucket() {
              //加载桶位，0-9共10个桶位
              Entry[] entries = new Entry[10];
              for (int i = 0; i < 10; i++)
                  entries[i] = new Entry();
              return entries;
          }
      
          public static int[] sort(int[] arr) {
              if (arr == null || arr.length <= 1)
                  return arr;
              Entry[] bucket = initBucket();
              int length = arr.length;
              //结果数组
              int[] res = new int[length];
              int start = 0;
              int remainCount = length;
              int zeroCount = 1;
              while (start < length) {
                  int bucketCount = 0;
                  //计算位数，个十百千万...
                  int div = (int) Math.pow(10, zeroCount - 1);
                  for (int i = 0; i < remainCount; i++) {
                      //数据位数不够的直接入新数组，不需要再次入桶倒桶
                      if (arr[i] < div) {
                          res[start++] = arr[i];
                          continue;
                      }
                      int index = arr[i] / div % 10;
                      //这里可以再优化，只放数据本身的下标替换存放数据本身，让桶内更轻量
                      bucket[index].nums.add(arr[i]);
                      bucketCount++;
                  }
                  //桶内元素数量为0时，说明顺序已经排好
                  //直接跳出循环
                  if (bucketCount == 0)
                      break;
                  remainCount = 0;
                  //没排好就继续加入旧的数组，继续入桶倒桶
                  for (Entry entry : bucket) {
                      for (Integer num : entry.nums)
                          arr[remainCount++] = num;
                      entry.clear();
                  }
                  zeroCount++;
              }
              return res;
          }
      
          public static void main(String[] args) {
              int[] arr = {22, 10, 30, 20, 80, 7, 50, 33};
              System.out.println(Arrays.toString(BucketSort.sort(arr)));
          }
      }
      ```

10. #### 桶排序：
