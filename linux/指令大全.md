1. SSH远程链接服务器：

   ```shell
   ssh [-P 端口号] root@192.168.1.178
   ```

2. 文件上传到服务器：

   ```shell
   scp [-P 端口] a.out root@192.168.1.178:/home
   ```

   

3. 文件下载到服务器：

   ```shell
   scp [-P 端口号] [-r表示下载的是文件夹] root@192.168.1.178:/home/a.out ./	
   ```

   

4. 连接某个服务器如:192.168.1.178:9000:

   ```shell
   nc 192.168.1.178 9000
   ```

5. vim/vi编辑器显示文本行数：

   ```shell
   :set nu
   ```

   

6. 复制整行数据：

   ```shell
   #vim在无法编辑的状态下
   yy (复制多行提前按个数，比如复制3行，按：3 yy)
   ```

   

7. 剪切整行数据：


8. 粘贴整行数据：

9. 监视网络套接字连接情况：

   ```shell
   netstat [-options]: 
   #	常用:netstat -natp 
   #	当然可以在后面添加管道进行筛选，
   #	比如:筛选端口号为9000的：netstat -natp | grep 9000
   #选项如下：
   options:
   	-a:all
   	-t:tcp
   	-u:udp
   	-p:programs(显示正在使用套接字的程序信息)
   	-r:route(显示路由表)
   	-n:numeric(不适用域名，直接使用ip地址)
   ```

37. 创建a.out的快捷方式abc：

    ```shell
    ln -s(选项。代表软连接，即符号链接) a.out abc
    # 如果不加-s选项，默认为硬链接方式，即在源文件的inode节点增加一个引用计数=2，两个文件名都指向同一个inode，删除其中一个文件名仅会使引用计数-1，计数不归零，源文件不会删除。
    #如果添加上了-s，表示创建符号链接。即创建了一个指向源文件的绝对路径的快捷方式，不会增加inode的引用计数。当删除源文件时，文件消失导致快捷方式失效，该链接就不可用
    ```

45. vim插入模式下光标位置的操作：

    ```shell
    #在光标的左边插入数据
    -i
    #将光标定位到当前行开头
    -I
    #光标定位到当前行末尾
    -A
    #光标所在行后面另起一行
    -o
    #光标所在行前面另起一行
    -O
    ```

    

46. vim 删除字符：

    ```shell
    #编辑模式下
    #删除光标后面的几个字符
    [n] x (n代表删除后面几个字符，不写默认1个)
    #删除光标前面的几个字符
    [n] X 
    #删除光标之后到该行末尾的所有字符
     D
    #删除光标开始到文件末尾的所有字符
    dG
    #删除光标所在行到文件开始的所有字符
    dgg
    ```
